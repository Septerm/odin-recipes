# odin-recipes

## Introduction

This is the first project for The Odin Project foundation course, its purpose is to demonstrate the usage of basic html and css for the creation of a simple recipe website.

## Tech Stack

- HTML
- CSS
- Git/GITHUB
- VS-CODE

## Skills Demonstrated 

- Correct creation of html boilerplate
- Proper usage of html tags and approprate usage of html elements for various types of content.
- Proper usage of anchor tags for the creation of both absolute and relative links.
- Proper usage of void tags , specifically img tags for embeding images on webpages. 
- Proper usage of alternative text in img tags, for accessbillity and SEO considerations.
- Correct usage of list tags, for both ordered and unordered items on websites.  
- Creation of proper directory structure for storing web-content (html files, image files , etc).
- Implementation of CSS stylesheet and usage of various selector (type, class and pseudo).
